# Barcode Reader — Klencod Template

قالب Flutter لقارئ QR والباركود باستخدام كاميرا الهاتف.

## المزايا

- قراءة QR وEAN وCode 128 وCode 39 وعدة أنواع أخرى.
- إطار مسح متحرك وتجربة كاميرا واضحة.
- تشغيل وإيقاف الفلاش.
- سجل محلي للنتائج مع حذف السجل.
- نسخ النتيجة إلى الحافظة.
- فتح الروابط المقروءة في المتصفح.
- عرض نوع الرمز ووقت القراءة.
- واجهة بديلة عند رفض إذن الكاميرا.

## ملاحظة البناء

يحتاج التطبيق إلى صلاحية الكاميرا. أضيفت الصلاحية في `AndroidManifest.xml`. استورد المشروع كاملًا داخل Klencod IDE واترك `pubspec.yaml` و`android/` في الجذر، ثم نفّذ Build APK.
